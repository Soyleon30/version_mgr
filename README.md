# 投产版本文件归集工具

这是一个仅使用 Go 标准库编写的命令行工具。它会在指定投产根目录下递归查找名为 `版本说明` 的目录，并把其中的普通文件归集到该目录最近的、名称以 `TS202` 开头的祖先目录。

归集规则：

- 文件名以 `版本说明书` 开头：复制到 `TS202...\版本说明书\`。
- 文件名以 `投产确认书` 开头：复制到 `TS202...\投产确认书\`。
- 其他文件：直接复制到对应的 `TS202...\`。
- `版本说明` 下还有子目录时，也会递归收集其中的文件。
- 目标已有同名同内容文件时跳过；同名但内容不同时自动命名为 `文件名 (2).扩展名`，不会覆盖已有文件。
- 找不到 `TS202*` 祖先、无法读取或不是普通文件的项目会显示为“忽略”。

## 编译

需要 Go 1.22 或更高版本：

```powershell
go build -o versionmgr.exe .
```

## 使用

先预览，不复制：

```powershell
.\versionmgr.exe -root "D:\20261009投产" -dry-run
```

查看计划并手动确认后复制：

```powershell
.\versionmgr.exe -root "D:\20261009投产"
```

无人值守执行：

```powershell
.\versionmgr.exe -root "D:\20261009投产" -yes
```

也可以直接双击或不带参数运行，程序会提示输入投产根目录。第一次对真实目录执行建议先使用 `-dry-run` 检查计划。
